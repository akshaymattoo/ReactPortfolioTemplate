My dad plays Wordle every evening. My five-year-old son noticed and got curious.

For a week, he would sit next to grandpa, excited to be involved—but the words were too hard. He would lose interest halfway through. That moment of wanting to participate but not being able to stuck with me.

I looked for a kid-friendly version with simple vocabulary, shorter words, and the same fun format. I could not find anything that felt right, so I asked Claude to help me build one.

It works like Wordle, with the same color logic and guessing mechanic, but it is designed for a five-year-old:

- Three-letter words only
- More than 200 kid-friendly words such as cat, dog, sun, hug, and dad
- Multiple tries with no daily restriction
- Everything contained in one static HTML file

There is no backend, database, or login. Now my son plays alongside grandpa: a different game at the same table.
