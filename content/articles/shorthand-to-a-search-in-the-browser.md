“Data is the new oil”, this phrase has been around for a while now. With more and more websites more data is being generated every day. When we install a browser it comes with a default search engine or asks us to make some engine a default one so our queries are directed to that particular one. But sometimes we need some other option to search for data. For that, we have shorthands that we can place before a query and it will direct our search to that website. For example, if we write, `!g what is the largest economy in the work` in the search bar of the browser it will direct us to google search with that query. These shorthands for the data search makes life a little easier. Below are a few common options.

*   `!y for yahoo`
*   `!g for google`
*   `!b for bing`
*   `!ddg for duck duck go`
*   `!f for Flickr`
*   `!fb for facebook`
*   `!li for linkedin`
*   `!so for stackoverflow`

I am sure there are many other options available too, but I find the above to be used more frequently.
